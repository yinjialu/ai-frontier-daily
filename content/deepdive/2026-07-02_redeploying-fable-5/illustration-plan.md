# 小黑配图策略

## 01 封面 / 首图：模型过闸

- 放置位置：文章开头或公众号封面。
- 核心意思：Fable 5 重新上线不是简单恢复，而是经过安全闸门和治理流程后的受控开放。
- 结构类型：概念隐喻。
- 小黑动作：小黑认真推着写有“Fable 5”的黑盒模型通过一个低科技安全闸门，闸门旁有四个小刻度盘。
- 建议元素：安全闸门、模型黑盒、四个小刻度盘、远处评估桌。
- 标注词：受控开放 / 安全闸 / Fable 5 / 评估中 / 恢复访问。

## 02 正文配图：越狱不是一个开关

- 放置位置：“争议点不在能不能越狱，而在越狱有多严重”之后。
- 核心意思：jailbreak 严重度不是二元判断，而要看能力增益、范围、武器化难度、可发现性。
- 结构类型：方法分层。
- 小黑动作：小黑把一个写着“jailbreak”的小石头放到一台四脚秤上，四个秤盘分别称不同维度。
- 建议元素：四脚秤、jailbreak 石头、红色警示刻度、蓝色备注。
- 标注词：能力增益 / 范围 / 武器化 / 可发现性 / 不是开关。

## 03 正文配图：发布变成治理流程

- 放置位置：“政府正在进入模型发布流程”或“前沿模型正在从产品变成受控能力”之后。
- 核心意思：前沿模型发布从单次上线，变成内部评测、外部安全伙伴、政府预评估、持续监控的闭环。
- 结构类型：系统局部。
- 小黑动作：小黑坐在一个怪工位前，把“模型发布”纸条依次塞进四个不同的检查抽屉，最后才打开“开放访问”的小门。
- 建议元素：四个抽屉、开放访问小门、回流线、记录本。
- 标注词：内部评测 / 安全伙伴 / 政府预评估 / 持续监控 / 开放访问。
