Claude Code 里有两个很容易混在一起的旋钮：模型和 effort。

官方这篇文章把它讲得很清楚：

模型决定能力边界。
effort 决定工作量预算。

模型选择，本质上是在换一组冻结权重。你的 prompt、CLAUDE.md、上下文文件能 steering 这一轮输出，但不会把知识写进模型本身。

effort 也不只是“多想一会儿”。它会影响 Claude 愿意读多少文件、调用多少工具、跑多少验证、在回来找你之前推进多少步骤。

所以当 Claude Code 做错时，别马上拉满设置。

先问一句：

它是不知道，还是没试够？

如果它有上下文，也认真试了，但还是理解错、判断错，换更强模型。

如果它跳过文件、没跑测试、没查证、重构半路停下，提高 effort。

但在这之前，更应该先检查任务上下文：复现步骤、测试命令、约束、验收标准、CLAUDE.md 有没有给清楚。

真正会用 Claude Code，不是永远用最强模型和最高 effort，而是学会给不同任务分配不同预算。
