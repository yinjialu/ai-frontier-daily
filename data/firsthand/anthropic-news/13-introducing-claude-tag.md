Anthropic 推出 Claude Tag，让 Claude 作为团队成员加入 Slack 频道，被 @Claude 标记即可委派任务。支持多人协作共享上下文、跨频道学习记忆、主动推送（ambient）和异步自主执行。权限按频道严格隔离，管理员可控工具访问与 token 预算。基于 Opus 4.8，面向 Enterprise/Team 客户 beta 开放，被视为 Claude Code 的演进。
