Anthropic 重新设计 Claude Code 桌面应用,核心是支持并行运行多个 Agent 任务。新增侧边栏统一管理多会话(可按状态/项目/环境筛选,PR 合并后自动归档),拖拽式布局,内置终端、文件编辑器、更快的 diff 查看器和扩展预览。支持侧边分支对话(⌘+;)、CLI 插件对等、Mac SSH 远程会话,以及 Verbose/Normal/Summary 三种视图模式和流式响应。定位用户为'编排者',面向'多任务并发'的 Agent 编程新形态。
