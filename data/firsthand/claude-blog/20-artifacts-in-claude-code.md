Anthropic 为 Claude Code 推出 artifacts:可将会话工作进度沉淀为实时、可交互、可共享的网页(如 PR 走查、仪表盘、故障排查时间线、发布清单)。基于完整会话上下文(代码库、connectors、对话)自动构建,无需自行接数据源;每次发布生成同链接新版本并保留历史,默认私有、仅组织内成员可见,管理员可控访问与留存。
