Anthropic 公布 Built with Opus 4.7 Claude Code 黑客松获奖项目。一等奖 Medkit 用 Claude Managed Agents 构建医学住院医师模拟问诊训练工具,作者跨 4 个 Claude Code 会话并行开发、全程语音操作;二等奖 Wrench Board 借助 Opus 4.7 视觉识图能力辅助电子维修,用 Claude Design 出规格、多 Agent 并行调试。展现 Claude 作为思考伙伴而非单纯代码生成器的价值。
