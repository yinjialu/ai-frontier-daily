Anthropic 推出 Claude Managed Agents 公测版,一套用于构建和部署云端托管 Agent 的组合式 API。它内置沙箱执行、状态检查点、凭据管理、细粒度权限和端到端追踪,并提供调优过的 orchestration harness 自动决定工具调用、上下文管理和错误恢复,号称将生产化周期从数月缩短到数天。支持长时运行会话、多 Agent 协同(research preview)及结果导向的自评迭代。Notion、Rakuten、Asana 等已落地应用。
