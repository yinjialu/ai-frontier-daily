Anthropic 推出 Claude Managed Agents——一套可组合的 API,将为 Claude 调优的 agent harness 与生产级基础设施(托管伸缩、会话管理、文件系统、凭证、可观测性)打包,让团队从原型到上线从数月缩短到数天。文章回顾了从 2023 年简单 API 到 Claude Code、Claude Agent SDK 再到 Managed Agents 的演进路径,主打免去自建 loop 与运维负担。
