Anthropic 销售经理 Jared Sires 入职前从未写过代码,借助 Claude Code 打造了 CLAFTS——一个嵌入 Gmail、调用 Claude API 按本人语气起草客户回复邮件的工具,每天省 2-3 小时,4300 行代码几乎全由 Claude Code 生成。他还做了账户增长排名简报、通话前背调、会议纪要生成跟进邮件等工具,并打包成 Claude Cowork 插件供整个销售团队使用,从 AE 转岗为 GTM 产品经理。
