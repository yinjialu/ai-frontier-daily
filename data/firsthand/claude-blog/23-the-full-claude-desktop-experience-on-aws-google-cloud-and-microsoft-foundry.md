Anthropic 宣布通过 AWS、Google Cloud、Microsoft Foundry 部署的 Claude Desktop 现已开放完整体验，整合 chat、Claude Cowork 和 Claude Code 于一体。企业可在自有云环境内运行推理、本地存储对话历史，并支持按用户 SSO、MDM 策略模板、离线安装及可完全本地运行的 M365 连接器；chat/Cowork/Code 各有独立策略密钥，便于按角色分阶段放权。
